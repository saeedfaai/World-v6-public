## Architecture contract

World 8 / Z0-A separates replaceable cognition from canonical identity, authority, objectives, accepted state, and history. The fixed topology has five planes: Canonical Spine, Operational, Observation, Development/Mason, and Evidence/Governance.

The release does **not** claim production readiness, consciousness, biological life, legal personhood, AGI, proven autonomous evolution, universal exactly-once effects, or complete security. Stronger claims remain evidence-gated.
