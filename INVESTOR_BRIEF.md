## Executive summary

World v6.2 is a model-independent architecture for building governed multi-agent and agentic AI systems in which identity, canonical truth, policy, authority, effects, memory and lifecycle are not delegated to any single model or provider.

The architecture is designed around a practical failure mode in agentic systems: model output can be useful without being trustworthy enough to directly become system truth, authority or irreversible external action. World v6.2 therefore separates cognition from governance, truth, execution and recovery through explicit contracts and deterministic boundaries.

This release is **not presented as a production-proven platform**. RC3 is a public ratification candidate with local component/contract evidence (`E2`). The commercial objective is to convert the architecture into paid pilots, enterprise deployments and licensable/OEM implementations while advancing evidence toward live integration and operational validation.

## What is differentiated

- **Stable Entity, replaceable Brain:** provider/model changes do not redefine identity or authority.
- **Proposal-only cognition:** model output is a proposal; policy and deterministic control determine what may become state or effect.
- **Canonical truth outside the model:** lower-resolution views are projections, never replacements for source truth.
- **Governed external effects:** approvals, transactional outbox, idempotent execution and reconciliation are explicit architectural boundaries.
- **Fractal operating model:** the same contract pattern repeats from World → Entity → Mission → Skill → Workflow → Step → Tool → Field.
- **Resolution-native context:** complexity can expand locally without silently degrading canonical state.
- **Portable model path:** the public release includes a provider-independent manual bridge based on self-contained JSON contracts.
- **Evolution without direct self-deployment:** shadow evidence can produce candidates, but promotion remains governed.
